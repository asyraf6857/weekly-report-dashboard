# Weekly Report Dashboard

A free, responsive GitHub Pages dashboard for Marine Services weekly report monitoring.

## Current features
- KPI cards: total visits, closed, Pilotage and CMC
- Search by vessel, visit number and invoice
- Filters by activity, status and week
- Activity doughnut chart
- Weekly visit bar chart
- Responsive visit detail table

## Data
`data.js` contains the dashboard data model. Replace/extend `REPORT_DATA` with the latest exported Excel rows.

## GitHub Pages
Repository: `asyraf6857/weekly-report-dashboard`

Enable Pages in **Settings → Pages → Deploy from branch → main → /(root)**.
